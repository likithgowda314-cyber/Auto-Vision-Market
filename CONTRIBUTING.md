# Contributing to AutoPrice 🤝

First off, thank you for considering contributing to AutoPrice! It's people like you that make AutoPrice such a great marketplace and tool.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub with:
* A clear description of the problem
* Steps to reproduce the bug
* Any relevant error messages or screenshots

### Suggesting Enhancements
We are always looking for ways to improve AutoPrice! If you have an idea, open an issue and explain your proposal. 

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes (`npm run build` / GitHub Actions).
5. Make sure your code lints.
6. Issue that pull request!

## Code Style
* **Frontend:** We use Next.js, React, and TailwindCSS. Keep components modular.
* **Backend:** We use Node.js and Express. Follow RESTful principles.
* **AI:** We use Python and PyTorch. Ensure `requirements.txt` is up to date if you add new dependencies.

Thank you for contributing! 🚀
